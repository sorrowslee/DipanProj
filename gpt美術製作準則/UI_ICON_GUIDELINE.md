# 《燃燈劫》UI / 裝備 / 道具 / 技能 Icon 繪製準則
**檔名：UI_ICON_GUIDELINE.md**

> 用途：製作《燃燈劫》的 UI 面板、按鈕、頁籤、框體、小圖示、裝備 icon、道具 icon、技能 icon、技能珠等。

---

## 1. 適用範圍

### UI
- 面板
- 按鈕
- 頁籤
- 關閉鈕
- 箭頭
- 背板
- 名稱框
- 選中框
- 未選中框
- 頁碼背景
- HUD 元件

### Icon
- 武器
- 裝備
- 道具
- 技能
- 技能珠
- Buff / Debuff
- 功能圖示
- 小型 UI 標誌

---

## 2. 核心目標

UI 不是「外掛在遊戲上面的軟體介面」，而是《燃燈劫》世界的一部分。

必須：

1. 與遊戲世界觀同語言。
2. 小尺寸仍清楚。
3. 同系列一致。
4. 主體優先，裝飾其次。
5. 方便拆分與實際程式使用。
6. 單一元件換風格時，不任意改動原始尺寸。

---

## 3. 整體 UI 語言

《燃燈劫》UI 可使用：

- 暗色木
- 黑鐵
- 石材
- 舊紙
- 佛器
- 暗金
- 暗紅
- 墨色
- 腐蝕
- 破損
- 顆粒
- 水墨
- 陰暗奇幻裝飾

避免：

- 現代 app 圓角卡片
- 科技藍玻璃 UI
- 明亮扁平化 icon
- 過度乾淨的 SaaS / 手機介面感

---

## 4. UI 元件一致性

同一套 UI 系統內，下列項目必須一致：

- 邊框粗細
- 尖角 / 倒角邏輯
- 內陰影
- 高光方式
- 材質
- 顆粒密度
- 裝飾位置
- 金屬 / 木 / 石的表現方式
- 選中與未選中的差異方式

不能：

- 每個按鈕不同畫風
- 每個頁籤不同材質
- 同一套框有的華麗、有的現代極簡

---

## 5. 單一元件換風格鐵則

當使用者提供既有 UI 並要求：

> 「只改風格」

則：

### 不可改
- 圖片尺寸
- 長寬比例
- 按鈕占比
- icon 的功能
- 點擊區形狀
- 元件的基本結構

### 可改
- 材質
- 顏色
- 線條
- 紋理
- 裝飾語言
- 光影方式

除非使用者明確要求，否則：

> **圖片尺寸絕對不要動。**

---

## 6. Icon 核心規則

設計順序：

1. 主體剪影
2. 功能辨識
3. 大色塊
4. 明暗
5. 裝飾

小尺寸下仍需辨識。

例如：

- 穿透：要看得出「穿過」
- 分裂：要看得出「一變多」
- 追蹤：要有目標 / 軌跡概念
- 反彈：要有折返 / 回彈方向
- 加速：要有速度感
- 傷害增加：要有力量 / 增幅感

---

## 7. 裝備 / 武器 Icon

- 武器本體是主角。
- 不要用背景特效掩蓋武器形狀。
- 武器輪廓需明確。
- 裝飾可以增加稀有度感，但不能改變物件辨識。
- 同一系列保持相同：
  - 鏡頭
  - 大小
  - 光影
  - 邊框 / 底座
  - 材質密度

---

## 8. 技能珠 / 等級系列

若有 LV1 / LV2 / LV3：

### 核心物件保持不變
差異主要表現於：

- 外框
- 金屬裝飾
- 額外紋樣
- 光感
- 細節豐富度

原則：

> 等級越高越豪華，但仍然一眼看得出是同一系列、同一顆珠子的升級版。

---

## 9. UI 色彩階層

### 基底
- 深灰
- 墨黑
- 暗紅
- 暗金
- 深褐
- 墨藍

### 高亮
只用於：

- 選中
- 稀有度
- 提示
- 警告
- 關鍵資訊
- 技能核心

不要整個介面所有區域都亮。

---

## 10. 可拆分性

因為《燃燈劫》常需要將 AI 生成圖拆成程式元件，因此生成時必須考慮：

- 底板可獨立
- icon 可獨立
- 文字可獨立
- 箭頭可獨立
- 裝飾可獨立
- 符號可獨立

若使用者要求拆圖：

1. 不要只截圖。
2. 應重新繪製成完整獨立元件。
3. 不可帶入周圍其他 UI。
4. 不切邊。
5. 保持原本比例與造型。

---

## 11. 文字圖規則

若文字本身是美術元件：

- 保持系列字體風格。
- 中文字形必須正確。
- 英文化時允許縮小或雙行排版。
- 不可為塞字而把整個底板比例改壞。
- 中英版應看起來是同一套 UI。

---

## 12. 禁止事項

- 不可變成手機 app 風。
- 不可過度華麗。
- 不可 icon 主體被裝飾吃掉。
- 不可縮小後糊成一團。
- 不可不同 icon 像不同遊戲的素材。
- 不可未經要求擅自改尺寸。
- 不可把「移除元件」理解成重畫整個區域。
- 不可拆元件時只做原圖裁切。

---

## 13. 新對話委託時需提供

1. 本準則。
2. 2～5 張目前已核准 UI / icon 範例。
3. 類型：UI / 武器 / 裝備 / 技能 / 道具 / 技能珠。
4. 使用尺寸或原圖。
5. 是否必須保持原始尺寸。
6. 是否需要透明背景。
7. 是否要拆成多個獨立元件。
8. 是否有選中 / 未選中 / 按下狀態。
9. 是否有 LV1～LV3 等系列要求。

---

## 14. 驗收檢查

- [ ] 小尺寸仍可辨識。
- [ ] 主體明確。
- [ ] 與現有 UI 同一套語言。
- [ ] 材質一致。
- [ ] 裝飾沒有壓過功能。
- [ ] 若為風格替換，尺寸未改。
- [ ] 若為拆圖，提供的是完整獨立元件，不是單純裁切。
- [ ] 同系列多張圖的鏡頭、大小與裝飾邏輯一致。
