# 《燃燈劫》AI 美術委託工作流程
**檔名：AI_COMMISSION_WORKFLOW.md**
> 收錄於美術規範準則資料夾（2026-08-28）｜總綱見 [../ART_DIRECTION.md](../ART_DIRECTION.md)，本準則為其分域實作；資料夾索引見 [README.md](README.md)。

> 用途：每次開新 ChatGPT / AI 對話時，用來建立穩定的美術委託流程。  
> 本文件不取代各類別準則；它規定「怎麼使用那些準則」。

---

## 1. 文件組成

目前《燃燈劫》的美術委託分為五類：

| 類型 | 使用文件 |
|---|---|
| 完整場景 | `SCENE_GUIDELINE.md` |
| 場景地上物 / 家具 | `SCENE_PROP_GUIDELINE.md` |
| 遊戲內人物 / 怪物圖 | `CHARACTER_SPRITE_GUIDELINE.md` |
| 對話人物立繪 | `CHARACTER_PORTRAIT_GUIDELINE.md` |
| UI / 裝備 / 道具 / 技能 icon | `UI_ICON_GUIDELINE.md` |

---

## 2. 新對話標準流程

每次新開一個對話，依序提供：

### Step 1｜準則
上傳本次委託所屬類別的 `.md` 檔。

### Step 2｜風格範例
提供 2～5 張已經認可的《燃燈劫》圖片。

最好包含：

- 1～2 張整體風格錨點
- 1～2 張同類型素材錨點
- 若是既有角色，再加 1 張該角色母版

### Step 3｜說明本次需求
說明：

- 要畫什麼
- 用在哪裡
- 尺寸 / 比例
- 朝向 / 視角
- 是否透明背景
- 哪些地方必須保持
- 哪些地方可以改

### Step 4｜確認後生成
若需求已完整，直接生成。
若有會明顯影響結果的關鍵缺口，再詢問。

---

## 3. 範例圖的角色

範例圖不是「大概參考」，而要分清楚用途。

### A. Style Anchor｜風格錨點
用來回答：

> 「《燃燈劫》到底長什麼樣？」

### B. Category Anchor｜類型錨點
例如：

- 角色 sprite 標準
- 立繪標準
- UI 標準
- 地上物標準

### C. Character Master｜角色母版
只用於既有角色。

用來回答：

> 「這個角色到底是誰？」

---

## 4. 角色母版制度

重要角色應先選定一張唯一母版。

一旦母版被使用者確認：

> **之後同角色所有新圖，以母版為最高優先級。**

不能因為新圖「單張更漂亮」就自行改掉：

- 臉
- 頭身
- 髮型
- 毛髮
- 身材
- 配色
- 配件
- 畫面占比
- rendering

---

## 5. LOCKED / CHANGE ONLY 制度

既有角色、既有 UI、既有元件的修改需求，建議都用兩區描述。

### LOCKED｜不可變
例如：

- 角色身份
- 頭身比例
- 髮型
- 服裝
- 朝向
- 圖片尺寸
- 背景
- UI 外框

### CHANGE ONLY｜本次只改
例如：

- 表情改成開心
- 右手舉高
- 移除紅光
- 把中文改成英文
- 把材質改成新版 UI 風格

AI 應把 LOCKED 視為硬限制，而不是參考。

---

## 6. 「其他都不要變」的正式定義

當使用者說：

> 「其他都不要變」

代表：

- 不重新構圖
- 不換鏡頭
- 不重做角色
- 不改光影
- 不改比例
- 不更換材質
- 不擅自修飾其他區域

只修改使用者明確指定的目標。

---

## 7. 新設計與修改任務要分開

### 新設計
可以探索多種方案。

例如：

- 設計狂族三階
- 設計新場景
- 設計新 UI

### 修改既有圖
應以「最小必要改動」為原則。

例如：

- 移除特效
- 改文字
- 換材質
- 改表情
- 移除背包

不要在修改任務中重新設計整張圖。

---

## 8. 一次不要量產太多角色差分

建議：

1. 先做母版。
2. 再做兩張差異大的測試差分。
3. 確認沒有漂移後再補齊整套。

原因：

如果第 2 張就已經漂，直接一次做 7 張只會放大返工成本。

---

## 9. 每張圖的驗收順序

不要第一個問題就問「漂不漂亮」。

應按順序：

### 1. 身份對不對？
- 同一角色嗎？
- 同一 UI 系列嗎？
- 同一場景世界嗎？

### 2. 規格對不對？
- 尺寸
- 視角
- 朝向
- 比例
- 裁切

### 3. 風格對不對？
- 像素密度
- 線條
- 材質
- 明暗
- 配色

### 4. 最後才是：
- 漂不漂亮？
- 表情夠不夠好？
- 細節是否需要提升？

---

## 10. 風格漂移處理方式

若新圖開始漂移：

不要繼續用錯誤的新圖當下一張參考。

應：

1. 回到最後一張已核准母版 / 錨點。
2. 列出漂移項目。
3. 重新 LOCK：
   - 比例
   - 臉型
   - 髮型
   - rendering
   - 畫面占比
4. 只保留本次需要的新動作 / 表情。
5. 重新生成或編修。

---

## 11. 場景素材一致性工作法

同一張地圖的素材最好：

- 同一批委託。
- 使用相同主色劇本。
- 互相附圖參照。
- 同一個視角。
- 同一個細節密度。

若之後補產單件素材，應附：

- 場景截圖
- 2～3 張已核准同場景物件

而不是只靠文字重新描述。

---

## 12. UI 一致性工作法

同一 UI 系統應固定：

- 底板
- 框
- 線條粗細
- 金屬 / 木 / 石材質
- 顆粒
- 高光
- 按下狀態
- 選中狀態

新元件應附已有 UI 範例，不讓 AI 自行重新發明一套。

---

## 13. 建議委託格式

可直接使用：

```text
這次是《燃燈劫》的【類型】委託。

請遵守我上傳的準則檔。

【用途】
……

【參考圖】
圖1：整體風格
圖2：同類型素材
圖3：角色母版 / 現有元件

【LOCKED｜不可變】
1. …
2. …
3. …

【CHANGE ONLY｜這次只改】
1. …
2. …

【尺寸 / 比例】
……

【朝向 / 視角】
……

確認需求後直接製作。
```

---

## 14. 對 AI 的執行要求

收到準則與範例後：

1. 以準則為規格。
2. 以使用者提供的核准範例為視覺依據。
3. 不自行用一般知識取代既有《燃燈劫》設定。
4. 若範例與文字衝突，以使用者最新明確指示為準。
5. 修改圖時遵守最小變更。
6. 同角色衍生圖優先維持母版。
7. 不因單張美感而犧牲系列一致性。

---

## 15. 最終目的

這套流程的目標不是保證 AI 永遠 100% 不漂移，而是把漂移變得：

- 更少
- 更容易發現
- 更容易修正
- 不會一錯連錯
- 不需要每個新對話重新建立整套規則

**一致性優先於單張炫技。**
