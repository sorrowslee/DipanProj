## 0. 為什麼要這份規格（開發端的立場）

程式會**自動**把每張圖放到畫面上：

- **立繪**：量出「不透明內容框」，縮成固定高度，貼齊對話框。
- **角色圖**：量出 idle 的可見身高，縮成固定世界高度；再把各動作的腳底拉到同一條線，並從最底下一段找腳來放影子。

這套自動化**只在每張圖的構圖都一樣時才準**。過去素材的構圖各自不同，開發端只好維護三套補正：

| 補正 | 目前筆數 | 在補什麼 |
|---|---|---|
| `PortraitTable.csv` | 11 列 | 立繪構圖不一（到膝蓋／到腳踝／蹲坐、帽子角太高、寬幅畫布），臉的大小與位置跑掉 |
| `ShadowAnchorTable.csv` 的 manual 列 | 24 列 | 披風、長袍、爪子、尾巴垂到腳邊，程式找不到腳 |
| MonsterData 逐動作倍率、`AttackOffsetX` | 17 個值 | 同一角色的 walk／attack 畫得比 idle 大或小（最多差 22%）、攻擊時身體偏移 |

量測依據（2026-11-08，全部現有素材）：

- 立繪畫布有 12 種尺寸。
- 60 個角色的 idle 在 256 畫布裡：
  - 腳底離底邊 21～91px；
  - 水平中心 104～146px；
  - 可見身高 76～213px。

**目標：照本規格交的新圖，上面三張表一列都不用加。** 表格只留給「刻意的構圖選擇」，不再拿來修素材誤差。

## 1. 共通規則（立繪與角色圖都適用）

1. **背景**：交圖用純平灰 `#808080`，或真透明 PNG（RGBA）。
   - **不可用黑底**：深色角色會被一起去掉。
   - 不可有地面、投影、場景、漸層、暗角、文字、簽名、浮水印。
2. **朝向：一律面向畫面右方**，3/4 側面。程式會自己鏡像出朝左的版本，**不要自己畫朝左的圖**。
3. **一張圖只有一個角色**。不畫特效、法術光、武器軌跡、飄散粒子（特效由程式另外疊）。
4. **不畫地面影子、接地暗斑**：遊戲內影子由程式畫，素材自帶影子會變成兩層。
5. **體型差異不畫進圖裡**。
   - 巨人、小怪、Boss 的大小差，由資料表的倍率控制（MonsterData `Scale`、BloodlineTable `BodyScale`）。
   - 所以**所有角色都照同一組對齊線畫滿**（§2.2、§3.2）。這條最常被違反：把巨人畫成佔滿畫布、小怪畫在角落，程式會把兩者縮成一樣高，結果反而失真。
6. **同一角色的立繪與角色圖是同一個設計**：臉、髮型、服裝結構、配色、配件要一致。
7. **頭身**：人形角色 4～4.5 頭身（沿用兩份準則）。
8. **色彩**：
   - 每個角色一個清楚主色、一個點綴色。
   - 暗部不用純黑 `#000000`，最亮處不用純白。
   - 角色是畫面明度第 3 層：要比地面亮、比特效暗（總綱紀律二）。

## 2. 對話立繪（Talk Portrait）

### 2.1 畫布

- **固定 1024 × 1536（2:3 直式）**，ChatGPT 的 2:3 輸出剛好是這個尺寸。
- **禁止**橫幅（1536×1024）、正方形、或其他比例。
  - 寬的角色（大裙襬、翅膀、蹲姿）也要收進直式畫布。
  - 要壓迫感是開發端放大的事，不是把畫布改寬。

### 2.2 對齊線（y 從畫布頂端往下量）

```
y = 0 ─────────────── 畫布頂
y = 40   ┄┄┄┄┄┄┄┄┄┄┄  頂部留白線：任何東西都不能高過這條
         ░ 頭頂飾品帶 ░  (40～180) 只准放：帽子、角、獸耳、翹起的頭髮、高舉的武器尖
y = 180  ━━━━━━━━━━━  頭頂線：頭骨／髮際的最高點（不含飾品）
y = 330  ━━━━━━━━━━━  眼線：雙眼的高度（±15）
y = 480  ┄┄┄┄┄┄┄┄┄┄┄  下巴（人形頭高 ≈ 300px，容差 ±20）
   …     身體
y = 1536 ━━━━━━━━━━━  畫布底：人物一定要被這條切掉（畫到腳踝，腳掌不入畫）
```

- **頭頂線 180、眼線 330、頭高 300px**：全部人形角色一樣。這是「每個人的臉在對話框裡一樣大」的唯一保證。
- **人物必須碰到畫布底邊**（底邊 0px 留白），從頭畫到腳踝。
  - 不可以畫到膝蓋就停、腳底還留空白。
  - 不可以畫成坐姿、蹲姿縮在下半部。
- **頭頂飾品帶（40～180）**：
  - 只能放頭上的東西；
  - 每個角色的所有表情要用**同一個高度**（帽子不能這張高、那張低）。
- **非人形（怪物、獸、巨像）**：
  - 頭頂線 180 改成「主體最高點」，眼線改成「主要的眼睛／臉」；
  - 一樣要碰到畫布底邊。
  - 臉可以比人形大（巨型怪可以只畫到腰，顯得更大），但頂線、底線不變。

### 2.3 水平位置（x 從畫布左邊往右量）

```
x = 64       ┃ 左界：背後（左側）的東西不可超出
x = 470±20   ┃ 身體中心線（脖子／脊椎）
x = 880      ┃ 右界：面向側（右側）的手、武器、袖子不可超出
x = 1024     ┃ 畫布右緣
```

- 角色面向右方，右側是**朝向對話框中央**的那一側。程式用「右緣」當對齊基準，所以：
  - **右緣不能忽遠忽近**：伸手、持武器都要收在 880 以內。
  - 同角色各表情的右緣差距 ≤ 30px。
- 主體寬度建議 420～700px。超過 816（64～880）一定會被程式縮小或推擠。

### 2.4 可見範圍：玩家實際看得到哪裡

- **對話時**：
  - 人物下面約 **22% 沉在對話框後面**。照本規格的畫布，大約 **y > 1200 的部分看不到**，畫面上看得到的是頭到大腿。
  - 所以手勢、表情、重要配件要放在 y < 1150。
  - 腰以下照樣要畫完整：角色介紹面板會露得比較多。
- **角色介紹面板**：人物頂端貼近畫面頂，下半身可能被畫面底切掉。

### 2.5 表情差分

- 情緒固定六種：`normal`、`happy`、`angry`、`cry`、`fear`、`hurt`。劇情需要時另外新增，名稱用英文小寫。
- 一律以 `normal` 為母版做差分。**對齊線、畫布、角色大小、站位完全不動**，只改：
  - 臉部表情；
  - 手勢；
  - 頭的小角度傾斜；
  - 身體重心（小幅度）。
- **驗收**：同角色各表情的不透明內容框，
  - 頂、底邊差 ≤ 1%；
  - 右緣差 ≤ 30px。

### 2.6 交付命名

| 種類 | 路徑（相對 `GameAssets/`） |
|---|---|
| 主角血統立繪 | `Main/Characters/Talk/<系列>/<血統>/<情緒>.png`（例 `Feralborn/Werewolf/angry.png`） |
| 關卡 NPC／怪物立繪 | `Modules/<關卡>/Talk/<角色>_<情緒>.png`（例 `BloodFang/Talk/Elvin_normal.png`） |
| 主線共用 | `Main/Talk/<角色>/<角色>_<情緒>.png` |

## 3. 遊戲內角色圖（Sprite／序列圖）

遊戲內動畫的流程是：先畫一張**基礎圖**，再交給 AutoSprite 產生各動作序列，最後切成 256×256 的單幀。本節同時規範基礎圖與序列成品。

### 3.1 基礎圖畫布

- **固定 1024 × 1024（1:1）**。
- 視角：3/4 側面、略帶俯視（top-down RPG），**面向右方**。
- 姿勢：自然站立，雙腳分開著地，四肢不互相大面積遮擋，武器完整入畫。

### 3.2 基礎圖對齊線（1024 畫布）

```
y = 96   ┄┄┄┄┄┄┄┄┄┄┄  頂部留白：任何東西都不能高過這條（角、帽、舉起的武器）
y = 176  ━━━━━━━━━━━  頭頂線：頭骨最高點（不含飾品）
y = 864  ━━━━━━━━━━━  腳底線：雙腳腳掌的最低點，必須剛好落在這條線
y = 1024 ─────────── 畫布底（腳底線以下 160px 必須全空）
x = 512  ┃            中心線：兩腳中點、身體重心
左右界 x = 160～864：身體主體不可超出（尾巴、披風、長武器可到 96～928）
```

- **可見身高 = 688px**（頭頂 176 → 腳底 864）：所有人形角色一樣，沒有例外。
- 換算成最後的 256 單幀：頭頂 y≈44、腳底 y≈216、中心 x=128。這就是現有素材的中位數，程式的預設值以它為準。
- **非人形**：
  - 頭頂線改成「主體最高點」，四足獸的腳底線一樣是 864。
  - 長條形（蛇、蟲）的身體貼著腳底線橫躺，高度可以低於 688，但最低點一定要在 864。
- **飛行角色**（蝙蝠、鬼魂、蝴蝶）：
  - 身體最低點放在 y = 760（懸空高度）；
  - 並在交付時註明「飛行」。程式會把影子放在地上，不跟著身體。

### 3.3 腳要讓程式找得到（影子的關鍵）

程式只在**最底下 15% 的高度帶**（y 760～864）找腳：找到兩段就當作兩隻腳，影子放在兩腳中間。

- **兩腳必須分開、看得見**，腳掌平踩在 864。
- **最底帶只能有腳**。以下東西的最低點都必須**高於 y = 780**：
  - 長袍下襬、披風、裙子、
  - 垂下的爪子、尾巴、
  - 鎖鏈、流蘇。
  - 長袍角色要露出鞋尖。
- 無腳角色（鬼魂、蛇、史萊姆）：最底下要是一段**平的接觸面**，寬度＝希望的影子寬，並在交付時註明。

### 3.4 序列成品（AutoSprite 輸出、切成單幀後）

| 項目 | 規格 |
|---|---|
| 單幀畫布 | **256 × 256**，RGBA 透明 |
| 動作資料夾 | `idle`（循環）、`walk`（循環）、`attack`、`dead`（必備）；選配：`slash`、`dodge`、`jump`、`jumpStart`、`jumpLanding`、`hang`、`pant` |
| 幀數 | 每個動作 **25 幀**（AutoSprite 5×5 合圖）；只有 perfect loop 版可以少於 25 |
| 檔名 | `<動作>/<動作>_01.png` ～ `_25.png`，兩位數補零 |
| 朝向 | 全部面向右 |
| 腳底線 | **每個動作的每一幀**，著地的腳都落在 y = 216 ±3（跳躍、浮空幀除外） |
| 身高 | 各動作的站立幀可見身高 = idle 的 **±4%**。走路的身體起伏、攻擊的前傾屬正常；整隻變大或變小不正常 |
| 水平 | 兩腳中點 x = 128 ±6。攻擊時可以往前踏，但最後一幀要回到中心 |
| 留白 | 任何一幀的內容都不能碰到畫布四邊（AutoSprite 的格線切割靠這個判斷） |
| 死亡 | 倒地後的身體貼著腳底線 216 橫躺，中心仍在 x = 128 附近；最後一幀停在倒地姿勢 |

- **所有動作都用同一張已核准的基礎圖產生**。不可以每個動作各自重畫一張基礎圖，否則角色大小一定會跑。
- 產完先檢查第 1 幀的腳底線與身高，對不上就重產，**不要交給程式去補**。

### 3.5 交付路徑

| 種類 | 路徑（相對 `GameAssets/`） |
|---|---|
| 主角血統 | `Main/Characters/SequenceImage/<系列>/<血統>/<動作>/<動作>_NN.png` |
| 主線怪物／NPC | `Main/Monsters/SequenceImage/<名稱>/<動作>/…` |
| 關卡怪物／NPC | `Modules/<關卡>/Monsters/SequenceImage/<名稱>/<動作>/…` |

## 4. 退件清單（出現任一條，該張作廢重畫）

### 共通

1. 黑底、場景底、漸層底；或圖裡有地面影子、特效、文字。
2. 面向左。
3. 用體型大小（佔畫布多少）表達角色的強弱或巨大。

### 立繪

4. 畫布不是 1024×1536。
5. 頭頂不在 y=180、眼睛不在 y=330，或頭高不在 280～320px（人形）。
6. 人物沒有碰到畫布底邊；坐姿、蹲姿，或畫到膝蓋就停。
7. 有東西高過 y=40；面向側的手或武器超過 x=880。
8. 同角色各表情的大小、站位、帽子高度不一致。

### 角色圖

9. 腳底不在腳底線（基礎圖 864／單幀 216），或兩腳中點不在中心線。
10. 長袍、披風、尾巴、爪子垂進最底帶，蓋住腳。
11. 同角色不同動作的身高差超過 ±4%，或不是用同一張基礎圖產生。
12. 任何一幀的內容碰到畫布邊緣。

## 5. Prompt 範本（單行貼上，換行會讓訊息提前送出）

### 5.1 新角色立繪母版

```
Generate an image now, no questions. Dialogue portrait of <角色描述>, dark fantasy Buddhist-horror game, same rendering style as the attached approved portraits, 4 to 4.5 heads tall, 3/4 view FACING RIGHT, standing, full figure from head down to the ankles with the bottom edge of the canvas cutting through the ankles (no feet visible, figure touches the bottom edge). STRICT LAYOUT on a 1024x1536 canvas: top of the skull at y=180 px, eyes at y=330 px, head height about 300 px, only hat/horns/ears may go above y=180 and nothing above y=40; body centerline at x=470; nothing on the right (facing) side beyond x=880, nothing on the left beyond x=64. No ground, no shadow, no effects, no text; plain flat grey #808080 background; 2:3 portrait output.
```

### 5.2 表情差分（附母版）

```
Generate an image now, no questions. Use the attached MASTER portrait. Change ONLY the facial expression and hand gesture to <情緒>. LOCKED: identical canvas, size, position, head height, eye line, hat height, outfit, colors and silhouette as the master; the figure still touches the bottom edge; plain flat grey #808080 background; 2:3 portrait output.
```

### 5.3 遊戲內角色基礎圖

```
Generate an image now, no questions. In-game character base sprite of <角色描述> for a top-down 2D action RPG, same style as the attached approved sprites, 3/4 side view with a slight top-down angle, FACING RIGHT, neutral standing pose with both feet apart and clearly visible, weapon fully visible. STRICT LAYOUT on a 1024x1024 canvas: top of the skull at y=176, soles of both feet exactly on y=864, midpoint between the feet at x=512, nothing above y=96, empty space below y=864; robes, capes, tails and claws must end above y=780 so the feet are not covered. No ground shadow, no effects, no text; plain flat grey #808080 background; 1:1 square output.
```

## 6. 驗收（開發端收圖時用程式量，交圖前請自己先對一次）

- [ ] **立繪**：畫布 1024×1536；內容碰到底邊；最高點 ≥ y40；右緣 ≤ x880；眼線約在 y330。
- [ ] **立繪**：同角色各表情疊在一起，大小、位置、帽子高度一致。
- [ ] **基礎圖**：腳底 y=864、兩腳中點 x=512、頭頂 y≈176，最底帶只有腳。
- [ ] **序列**：每個動作第 1 幀的腳底 y=216±3、中心 x=128±6、身高是 idle 的 ±4%，所有幀都不碰邊。
- [ ] **共通**：面向右、無影子、無特效、無文字，和母版是同一個角色。

## 7. 開發端說明（繪圖協力可略過）

- **合規素材＝補正表不用填**：
  - `PortraitTable.csv` 只留給刻意的構圖選擇，例如作者要某個 Boss 放大 1.2 倍製造壓迫感。
  - ShadowAnchor 只留 auto。
  - MonsterData 的逐動作倍率、`AttackOffsetX` 留空。
- **既有素材不追溯**：已經進遊戲的圖照舊靠補正表。重畫時才照本規格。
- **待作者決定的程式調整（尚未實作）**：
  - 立繪若全面符合 §2，`PortraitFit` 可以改成用固定對齊線（頭頂線、眼線）排版，不再量內容框。這樣頭頂飾品高低就完全不影響臉的大小。
  - 可以寫一支收圖驗證工具，自動量 §6 的各項數值並列出不合格的圖。
