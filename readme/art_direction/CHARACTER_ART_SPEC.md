## 0. 為什麼要這份規格（開發端的立場）

程式會**自動**把每張圖放到畫面上：

- **立繪**：量出「不透明內容框」，縮成固定高度，貼齊對話框。
- **角色圖**：量出 idle 的可見身高，縮成固定世界高度；再把各動作的腳底拉到同一條線，並從最底下一段找腳來放影子。

這套自動化**只在每張圖的構圖都一樣時才準**。過去素材的構圖各自不同，開發端只好維護三套補正：

| 補正 | 目前筆數 | 在補什麼 |
|---|---|---|
| `PortraitTable.csv` | 11 列 | 立繪構圖不一（到膝蓋／到腳踝／蹲坐、帽子角太高、寬幅畫布），臉的大小與位置跑掉 |
| `ShadowAnchorTable.csv` 的 manual 列 | 24 列 | 披風、長袍、爪子、尾巴垂到腳邊，程式找不到腳 |
| MonsterData 逐動作倍率、`AttackOffsetX` | 17 個值 | 同一角色的 walk／attack 畫得比 idle 大或小（最多差 22%）、攻擊時身體偏移 |

量測依據（2026-11-08，全部現有素材）：

- 立繪畫布有 12 種尺寸。
- 60 個角色的 idle 在 256 畫布裡：
  - 腳底離底邊 21～91px；
  - 水平中心 104～146px；
  - 可見身高 76～213px。

**目標：照本規格交的新圖，上面三張表一列都不用加。** 表格只留給「刻意的構圖選擇」，不再拿來修素材誤差。

## 1. 共通規則（立繪與角色圖都適用）

1. **背景**：交圖用純平灰 `#808080`，或真透明 PNG（RGBA）。
   - **例外：角色本身以灰色為主**（灰毛狼人、石像、灰袍）→ 改用純平洋紅 `#FF00FF`，否則去背會把灰色的身體一起去掉（2026-11-08 狼人士兵實例）。
   - **不可用黑底**：深色角色會被一起去掉。
   - 不可有地面、投影、場景、漸層、暗角、文字、簽名、浮水印。
2. **朝向：一律面向畫面右方**，3/4 側面。程式會自己鏡像出朝左的版本，**不要自己畫朝左的圖**。
3. **一張圖只有一個角色**。不畫特效、法術光、武器軌跡、飄散粒子（特效由程式另外疊）。
4. **不畫地面影子、接地暗斑**：遊戲內影子由程式畫，素材自帶影子會變成兩層。
5. **體型差異不畫進圖裡**。
   - 巨人、小怪、Boss 的大小差，由資料表的倍率控制（MonsterData `Scale`、BloodlineTable `BodyScale`）。
   - 所以**所有角色都照同一組對齊線畫滿**（§2.2、§3.2）。這條最常被違反：把巨人畫成佔滿畫布、小怪畫在角落，程式會把兩者縮成一樣高，結果反而失真。
6. **同一角色的立繪與角色圖是同一個設計**：臉、髮型、服裝結構、配色、配件要一致。
7. **頭身**：人形角色 4～4.5 頭身（沿用兩份準則）。
8. **色彩**：
   - 每個角色一個清楚主色、一個點綴色。
   - 暗部不用純黑 `#000000`，最亮處不用純白。
   - 角色是畫面明度第 3 層：要比地面亮、比特效暗（總綱紀律二）。

## 2. 對話立繪（Talk Portrait）

### 2.0 ⭐ 現行標準：主角對話立繪（窄版＝長版 1024×1536／寬版 1536×1024）（2026-11-25 重寫；與下方 §2.1～§2.4、§5.1、§5.2 衝突時以本節為準）

> **為什麼重寫**（2026-11-25 作者：「把窄版跟寬版的對話立繪規格都設定好，都已經製作到 13 個血統了，還老是在寬版的立繪上出問題」）：
> 舊版本節只有幾條對齊線，沒寫「畫面上實際看得到哪裡」，而且 AI 自己加了一條作者從沒定過的規則
> 「腰線以下的手腳不能露出對話框外」——照它修了機偶暴君、深淵狂徒，結果把人縮小（腳懸空）又把框外的腳淡掉（缺一塊）。
> 現行 40 多組立繪裡，天使、路西法、年、九尾天狐的翅膀／尾巴本來就露在框外約 490px，**框外露出是正常的**。
> 本節所有數字都是照程式（`TalkPanel.SetAvatarWaistUp`、`BloodlineIntroPanel` 規格路徑）算出來的，改程式要回來改這裡。

#### 2.0.1 兩種畫布與對齊線（y 從畫布頂往下、x 從畫布左往右）

| 項目 | 窄版（長版）1024×1536（預設） | 寬版 1536×1024 | 程式怎麼用 |
|---|---|---|---|
| 頭頂線（**整個角色身體的最高點**：人形＝頭頂；巨獸、機器＝頭／煙囪頂。不含角、耳、髮尖、蒸汽） | y = 235 | y = 157 | → 畫面 y 975 |
| 腰線 | y = 800 | y = 533 | → 對話框上緣（畫面 y 577）；轉換面板的立繪底線 |
| 身體中心線（脖子／脊椎；巨獸＝兩腳中間） | x = 470 | x = 700 | → 離畫面中心 ±500；轉換面板的中心 |
| **最低點（腳底）** | **貼畫布底 y = 1535** | **貼畫布底 y = 1023** | 畫布底 → 畫面 y 59（人站在畫面底） |
| 畫布 1px ＝ 畫面幾單位 | 0.704 | 1.057 | 兩種顯示高都是 1082，所以**同樣的人在寬版畫布上要畫成 2/3 大** |
| 面向 | 3/4 側、面向右（右側立繪由程式鏡像） | 同左 | |

- **全身、腳貼畫布底，兩種版型都一樣**。⚠ 不准為了「讓腰剛好對到腰線」把人縮小——腰線只是程式拿來算倍率的線，
  人形照比例畫自然會落在附近；**巨獸、機器這種腿短身寬的，最高點＝頭頂線、最低點＝畫布底，腰落在哪裡就在哪裡**
  （通常比腰線低，對話框會切在胸口或上腹，看起來更大隻——可以）。縮小到腰對腰線的話，腳會停在畫布 80% 高、
  框外看得到的下半身就懸在半空（2026-11-25 機偶暴君、深淵狂徒）。
- 重排既有的圖一律用 `tools/art/art_remake/tools/fit_talk_portrait.py`（六張共用 normal 的倍率、每張腳貼底、下半身中心對身體中心線；
  轉換面板臉太偏就用 `--cx` 整組平移），不要再每張手寫腳本。

#### 2.0.2 對話框裡實際看得到哪裡（左側立繪；右側是鏡像）

畫面座標：原點在畫面中央底部，x 往外為負（左側立繪）、y 往上。標準 16:9 的 UI 是 1920×1080；
**作者的螢幕（1780×931，CanvasScaler match 0.5）UI 約 1991×1041——頂端少了約 39、左右多了約 35**。

| 區域 | 畫面範圍 | 換成畫布（窄版） | 換成畫布（寬版） | 規則 |
|---|---|---|---|---|
| 對話框（蓋住立繪） | x ±750、y 24～577 | 身體中心 x 往後 355 以內、y > 800 | 往後 237 以內、y > 533 | 被蓋住的部分照樣要畫完整（轉換面板、截圖會看到） |
| **框外、腰線以下** | x < −750 或畫面中央另一側 | x < 115 且 y > 800 | x < 463 且 y > 533 | **看得到，而且是設計**：翅膀、尾巴、斗篷、腳、垂下的手都可以。**必須完整**——不准切、不准淡掉、不准懸空（腳要貼畫布底） |
| 頂端（作者螢幕） | y ≤ 1041 | y ≥ 141 | y ≥ 94 | 高過去會被作者螢幕切掉：只能是角、耳、髮尖、蒸汽；**身體（頭、帽子、煙囪、舉高的拳頭）不行** |
| 程式自動下推線 | y > 1072 | y < 97 | y < 65 | 內容最高點高過這裡，程式把整張往下推（腰跟著下沉） |
| 外側畫面邊（16:9 ±960／作者 ±995） | | 不會出畫面 | x < 265（作者 232）出畫面 | 寬版外側的翅膀、尾巴被畫面邊切掉沒關係 |
| 畫布左右邊本身 | | **落在畫面 ±831，看得到** | 落在 ±1240，看不到 | 窄版**四周留白 ≥ 64px**，內容碰到畫布左右邊會是一條硬切直線（程式羽化 7% 只能柔化）；太寬塞不下＝改用寬版 |
| 面向側越過畫面中線（會壓到對面的人） | x > 0 | x > 1180（不會發生） | x > 1173 | 翅膀、尾巴尖越過可以；身體、臉不行 |

#### 2.0.3 血統轉換面板（`BloodlineIntroPanel`）

- 固定倍率：頭頂線 → 框頂下 165、腰線（窄 800／寬 533）→ 立繪底線；身體中心線（470／700）→ 破碎框中心。
- 只露出框內黑底一條窄窗：窄版中心線 **−152～+166 px**（x 318～636）、寬版 **−101～+111 px**（x 599～811）；上到框頂下 0.12。
- **臉（眼睛）要落在這條窄窗內**。面向右的 3/4 側臉常偏右（獸頭、前傾、巨人更明顯）——偏了就**整組六張一起水平平移**
  （`fit_talk_portrait.py --cx`），不要只動 normal。

#### 2.0.4 窄版還是寬版

- **預設窄版；寬版要作者指定**（§2.1〈寬體型例外〉，2026-11-08 作者定：繪圖方、AI 不可自行判定）。
  判斷參考（提給作者時用）：照 §2.0.1 全身擺好後，左右塞不進窄版的 64～960（翅膀、尾巴、巨軀、觸手）。
  實例（寬版）：天使、路西法（翅膀）、九尾天狐（尾巴）、年、毛殭、蟲皇、機偶暴君、深淵狂徒（巨軀／觸手）。
- 寬版畫布＝窄版的 2/3 縮放：同一個人在寬版上頭高、身高都是窄版的 2/3，兩者在遊戲裡一樣大。
- 同一角色六張表情用同一種版型。

#### 2.0.5 表情差分

- 六張共用同一個倍率（以 normal 為準），**每一張腳都貼畫布底**。
- 人形：頂、底差 ≤ 1%、面向側右緣差 ≤ 30px（§2.5）；臉的位置不能跳。
- 非人形的大動作表情（蹲下、縮成一團、張開觸手）：頭會比較低是對的（人站在地上），但臉在轉換面板窄窗內、身體不高過作者螢幕頂。

#### 2.0.6 交件前（開發端）

```
python3 tools/art/art_remake/tools/check_bloodline_portraits.py <系列>/<角色>   # 先驗再覆蓋：TALK=<候選根目錄> 指過去
```
- `FAIL` 一定要修：畫布不是規格尺寸、缺表情、**腳懸空**（框外看得到下半身但最低點沒貼畫布底）、內容超出畫面頂、轉換面板窗幾乎是空的。
- `WARN` 每條都要對著 sheet 看：高過作者螢幕頂（橘線）的是不是只有角／蒸汽；窄版碰到畫布左右邊；轉換面板臉有沒有被裁；表情框不一致。
- **框外露出不是 WARN，也不是問題。**
- 全體盤點（每個血統一行：頂端、腳離畫面底、框外露出、越過中線）：`python3 tools/art/art_remake/tools/audit_talk_portraits.py`。
- 其他：背景（母版洋紅 #FF00FF、紫粉色系改灰 #808080；差分純黑）、去背工具與 prompt 見 [../CHATGPT_IMAGE_WORKFLOW.md](../CHATGPT_IMAGE_WORKFLOW.md)「立繪統一重繪流程」。
- 對話框立繪在 `Main/Characters/Talk/*` 下、尺寸符合本節的，程式直接走上述排法，**不查 PortraitTable**（詳見 [../DRAMA.md](../DRAMA.md)〈腰部以上版面〉）。

### 2.1 畫布

- **固定 1024 × 1536（2:3 直式）**，ChatGPT 的 2:3 輸出剛好是這個尺寸。
- 除了下面的「寬體型例外」，**禁止**橫幅、正方形或其他比例。
  - 一般角色有大裙襬、翅膀、張開的手臂，也要收進直式畫布。
  - 要壓迫感是開發端放大的事，不是把畫布改寬。

#### 寬體型例外（2026-11-08 作者指定）（⚠ 下面的對齊線數值是舊版，已被 §2.0 取代）

有些角色是**設計上刻意很寬**：刻意肥胖、龐大的裙撐或斗篷、橫向展開的巨型身軀。
硬塞進直式畫布，人物會被縮得很小。實例：夏綠蒂公爵是刻意畫得很胖的角色。這類角色照以下規則：

- **只有作者在委託時明說「寬體型」才適用**，繪圖方不可自行判定。
- 畫布改為 **1536 × 1024（3:2 橫式）**。
- 對齊線依畫布高度等比換算（y 從畫布頂端往下量）：
  - 頂部留白線 y=27；
  - 頭頂線 y=120；
  - 眼線 y=220；
  - 人形頭高約 200px（容差 ±14）。
- 人物一樣要**碰到畫布底邊**，一樣面向右。
- 水平位置：
  - 身體中心線 x = 700±30；
  - 左界 x=64、右界（面向側）x=1440。
- 同角色所有表情都用同一個橫式畫布與對齊線。
- 交付時註明「寬體型」。開發端會在 `PortraitTable.csv` 給這個角色固定的放大倍率與 `OuterToScreen`，這是表格的正當用途，不算補素材誤差。

### 2.2 對齊線（y 從畫布頂端往下量）（⚠ 舊版數值，已被 §2.0 取代；保留供對照）

```
y = 0 ─────────────── 畫布頂
y = 40   ┄┄┄┄┄┄┄┄┄┄┄  頂部留白線：任何東西都不能高過這條
         ░ 頭頂飾品帶 ░  (40～180) 只准放：帽子、角、獸耳、翹起的頭髮、高舉的武器尖
y = 180  ━━━━━━━━━━━  頭頂線：頭骨／髮際的最高點（不含飾品）
y = 330  ━━━━━━━━━━━  眼線：雙眼的高度（±15）
y = 480  ┄┄┄┄┄┄┄┄┄┄┄  下巴（人形頭高 ≈ 300px，容差 ±20）
   …     身體
y = 1536 ━━━━━━━━━━━  畫布底：人物一定要被這條切掉（畫到腳踝，腳掌不入畫）
```

- **頭頂線 180、眼線 330、頭高 300px**：全部人形角色一樣。這是「每個人的臉在對話框裡一樣大」的唯一保證。
- **人物必須碰到畫布底邊**（底邊 0px 留白），從頭畫到腳踝。
  - 不可以畫到膝蓋就停、腳底還留空白。
  - 不可以畫成坐姿、蹲姿縮在下半部。
- **頭頂飾品帶（40～180）**：
  - 只能放頭上的東西；
  - 每個角色的所有表情要用**同一個高度**（帽子不能這張高、那張低）。
- **非人形（怪物、獸、巨像）**：
  - 頭頂線 180 改成「主體最高點」，眼線改成「主要的眼睛／臉」；
  - 一樣要碰到畫布底邊。
  - 臉可以比人形大（巨型怪可以只畫到腰，顯得更大），但頂線、底線不變。

### 2.3 水平位置（x 從畫布左邊往右量）（⚠ 舊版，已被 §2.0 取代）

```
x = 64       ┃ 左界：背後（左側）的東西不可超出
x = 470±20   ┃ 身體中心線（脖子／脊椎）
x = 880      ┃ 右界：面向側（右側）的手、武器、袖子不可超出
x = 1024     ┃ 畫布右緣
```

- 角色面向右方，右側是**朝向對話框中央**的那一側。程式用「右緣」當對齊基準，所以：
  - **右緣不能忽遠忽近**：伸手、持武器都要收在 880 以內。
  - 同角色各表情的右緣差距 ≤ 30px。
- 主體寬度建議 420～700px。超過 816（64～880）一定會被程式縮小或推擠。

### 2.4 可見範圍：玩家實際看得到哪裡（⚠ 舊版，已被 §2.0.2 取代）

- **對話時**：
  - 人物下面約 **22% 沉在對話框後面**。照本規格的畫布，大約 **y > 1200 的部分看不到**，畫面上看得到的是頭到大腿。
  - 所以手勢、表情、重要配件要放在 y < 1150。
  - 腰以下照樣要畫完整：角色介紹面板會露得比較多。
- **角色介紹面板**：人物頂端貼近畫面頂，下半身可能被畫面底切掉。

### 2.5 表情差分

- 情緒固定六種：`normal`、`happy`、`angry`、`cry`、`fear`、`hurt`。劇情需要時另外新增，名稱用英文小寫。
- 一律以 `normal` 為母版做差分。**對齊線、畫布、角色大小、站位完全不動**，只改：
  - 臉部表情；
  - 手勢；
  - 頭的小角度傾斜；
  - 身體重心（小幅度）。
- **驗收**：同角色各表情的不透明內容框，
  - 頂、底邊差 ≤ 1%；
  - 右緣差 ≤ 30px。

## 3. 遊戲內角色圖（Sprite／序列圖）

遊戲內動畫的流程是：先畫一張**基礎圖**，再交給 AutoSprite 產生各動作序列，最後切成 256×256 的單幀。本節同時規範基礎圖與序列成品。

> 📁 **基礎圖（及其他「遊戲用不到、但重做時需要」的美術原始檔）放 repo 根目錄 `ArtSource/`**（2026-11-13 作者定）：在 Unity 專案外（不匯入、不產 .meta、不打包），但**要進 git**。血統角色圖放 `ArtSource/Bloodlines/<系列>/`（系列名同 `SequenceImage/` 底下的英文資料夾：Jiangshi、Bloodborn、Feralborn…；主角放 `Base/`），每個系列放三階角色圖。`TempImage/` 才是真正的暫存（不進 git）。

### 3.1 基礎圖畫布

- **固定 1024 × 1024（1:1）**。
- 視角：3/4 側面、略帶俯視（top-down RPG），**面向右方**。
- 姿勢：自然站立，雙腳分開著地，四肢不互相大面積遮擋，武器完整入畫。

### 3.2 基礎圖對齊線（1024 畫布）

```
y = 96   ┄┄┄┄┄┄┄┄┄┄┄  頂部留白：任何東西都不能高過這條（角、帽、舉起的武器）
y = 176  ━━━━━━━━━━━  頭頂線：頭骨最高點（不含飾品）
y = 864  ━━━━━━━━━━━  腳底線：雙腳腳掌的最低點，必須剛好落在這條線
y = 1024 ─────────── 畫布底（腳底線以下 160px 必須全空）
x = 512  ┃            中心線：兩腳中點、身體重心
左右界 x = 160～864：身體主體不可超出（尾巴、披風、長武器可到 96～928）
```

- **可見身高 = 688px**（頭頂 176 → 腳底 864）：所有人形角色一樣，沒有例外。
- 換算成最後的 256 單幀：頭頂 y≈44、腳底 y≈216、中心 x=128。這就是現有素材的中位數，程式的預設值以它為準。
- **非人形**：
  - 頭頂線改成「主體最高點」，四足獸的腳底線一樣是 864。
  - 長條形（蛇、蟲）的身體貼著腳底線橫躺，高度可以低於 688，但最低點一定要在 864。
- **飛行角色**（蝙蝠、鬼魂、蝴蝶）：
  - 身體最低點放在 y = 760（懸空高度）；
  - 並在交付時註明「飛行」。程式會把影子放在地上，不跟著身體。

### 3.3 腳要讓程式找得到（影子的關鍵）

程式只在**最底下 15% 的高度帶**（y 760～864）找腳：找到兩段就當作兩隻腳，影子放在兩腳中間。

- **兩腳必須分開、看得見**，腳掌平踩在 864。
- **最底帶只能有腳**。以下東西的最低點都必須**高於 y = 780**：
  - 長袍下襬、披風、裙子、
  - 垂下的爪子、尾巴、
  - 鎖鏈、流蘇。
  - 長袍角色要露出鞋尖。
- 無腳角色（鬼魂、蛇、史萊姆）：最底下要是一段**平的接觸面**，寬度＝希望的影子寬，並在交付時註明。

### 3.4 序列成品（AutoSprite 輸出、切成單幀後）

| 項目 | 規格 |
|---|---|
| 單幀畫布 | **256 × 256**，RGBA 透明 |
| 動作資料夾 | `idle`（循環）、`walk`（循環）、`attack`、`dead`（必備）；選配：`slash`、`dodge`、`jump`、`jumpStart`、`jumpLanding`、`hang`、`pant` |
| 幀數 | 每個動作 **25 幀**（AutoSprite 5×5 合圖）；只有 perfect loop 版可以少於 25 |
| 檔名 | `<動作>/<動作>_01.png` ～ `_25.png`，兩位數補零 |
| 朝向 | 全部面向右 |
| 腳底線 | **每個動作的每一幀**，著地的腳都落在 y = 216 ±3（跳躍、浮空幀除外） |
| 身高 | 各動作的站立幀可見身高 = idle 的 **±4%**。走路的身體起伏、攻擊的前傾屬正常；整隻變大或變小不正常 |
| 水平 | 兩腳中點 x = 128 ±6。攻擊時可以往前踏，但最後一幀要回到中心 |
| 留白 | 任何一幀的內容都不能碰到畫布四邊（AutoSprite 的格線切割靠這個判斷） |
| 死亡 | 倒地後的身體貼著腳底線 216 橫躺，中心仍在 x = 128 附近；最後一幀停在倒地姿勢 |

- **所有動作都用同一張已核准的基礎圖產生**。不可以每個動作各自重畫一張基礎圖，否則角色大小一定會跑。
- 產完先檢查第 1 幀的腳底線與身高，對不上就重產，**不要交給程式去補**。

### 3.5 交付路徑

|---|---|
| 主角血統 | `Main/Characters/SequenceImage/<系列>/<血統>/<動作>/<動作>_NN.png` |
| 主線怪物／NPC | `Main/Monsters/SequenceImage/<名稱>/<動作>/…` |
| 關卡怪物／NPC | `Modules/<關卡>/Monsters/SequenceImage/<名稱>/<動作>/…` |

## 4. 退件清單（出現任一條，該張作廢重畫）

### 共通

1. 黑底、場景底、漸層底；或圖裡有地面影子、特效、文字。
2. 面向左。
3. 用體型大小（佔畫布多少）表達角色的強弱或巨大。

### 立繪

4. 畫布不是 1024×1536（作者指定的寬體型才可用 1536×1024，見 §2.1）。
5. 頭頂不在 y≈235（寬版 157）±25，或明顯比其他已核准立繪大／小（見 §2.0）。
6. 人物沒有碰到畫布底邊；坐姿、蹲姿，或畫到膝蓋就停（§2.0 起改為全身入畫，腳碰底邊）。
7. 身體高過作者螢幕可見頂（窄 y < 141／寬 y < 94；角、耳、髮尖、蒸汽除外）；窄版內容碰到畫布左右邊（§2.0.2）。
7b. **腳懸空**：最低點沒貼畫布底（§2.0.1）；或框外的部分被切掉、淡掉。
8. 同角色各表情的大小、站位、帽子高度不一致。

### 角色圖

9. 腳底不在腳底線（基礎圖 864／單幀 216），或兩腳中點不在中心線。
10. 長袍、披風、尾巴、爪子垂進最底帶，蓋住腳。
11. 同角色不同動作的身高差超過 ±4%，或不是用同一張基礎圖產生。
12. 任何一幀的內容碰到畫布邊緣。
