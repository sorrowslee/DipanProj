# 《燃燈劫》人物 / 怪物對話立繪繪製準則
**檔名：CHARACTER_PORTRAIT_GUIDELINE.md**
> 收錄於美術規範準則資料夾（2026-08-28）｜總綱見 [../ART_DIRECTION.md](../ART_DIRECTION.md)，本準則為其分域實作；資料夾索引見 [README.md](README.md)。

> 用途：製作《燃燈劫》劇情、對話時使用的人物 / 怪物立繪，以及同角色不同情緒差分。  
> 本文件特別重視「同角色跨多張圖的一致性」。

---

## 1. 適用範圍

- 主角對話立繪
- NPC 對話立繪
- Boss 對話立繪
- 怪物立繪
- 血統立繪
- 同角色普通 / 憤怒 / 難過 / 害怕 / 開心 / 受傷 / 驕傲 / 無語等差分

---

## 2. 核心目標

立繪最重要的不是「每張單獨都很漂亮」，而是：

> **全部放在一起時，玩家確信這是同一個角色。**

必須：

1. 同角色跨張高度一致。
2. 角色比例不漂。
3. 畫風不漂。
4. 裁切與人物占比穩定。
5. 情緒動作有差異，但角色身份不變。
6. 與遊戲內角色圖屬同一個設計。

---

## 3. 固定規格

- 畫面比例：**2:3 直式**
- 常用尺寸：**1024 × 1536**
- 類型：**Pixel art 2D RPG dialogue portrait**
- 構圖：全身或接近全身
- 背景：通常為乾淨黑底 / 指定純色底
- 人物不同情緒間的畫面占比應盡量一致

---

## 4. 固定畫風

> **High-detail pixel-art portrait, dark fantasy, crisp pixel clusters, clean large shapes, strong silhouette.**

執行：

- 保留明確 pixel-art 質感。
- 細節可以高，但不能變成平滑半寫實插畫。
- 大明暗與大形優先。
- 五官保留遊戲角色化。
- 不做動漫海報式細線。
- 不做油畫式寫實塑形。
- 不使用大量模糊漸層代替像素明暗。

---

## 5. 頭身比例鐵則

### 固定核心：4～4.5 頭身

- 頭明顯偏大。
- 身體不能拉長。
- 腿不能突然變成人體模特兒比例。
- 強者、王者、神性、邪氣，靠：
  - 姿態
  - 肩背
  - 剪影
  - 眼神
  - 配色
  - 特徵
  表現，不靠增高。

---

## 6. 方向與鏡頭

- 每個角色需有固定主要朝向。
- 朝左 / 朝右 / 3/4 side 依角色設定。
- 同一套立繪可有小幅頭部、身體轉動，但不得每張像不同拍攝角度。
- 不可一張近、一張遠。
- 不可不同情緒突然改成完全不同構圖。

---

## 7. 母版制度｜最重要

### 第一步：先建立普通版母版

母版必須確認：

- 頭身
- 臉型
- 眼睛
- 嘴 / 狼吻 / 鼻型
- 髮型
- 毛髮輪廓
- 身材
- 衣裝
- 配件
- 主色
- 特殊器官
- 朝向
- 光影
- 像素密度
- 畫面占比

經使用者確認後，標記為：

> **MASTER APPROVED / 唯一標準母版**

---

## 8. 所有表情圖都是「母版差分」

後續不可把角色重新描述一遍後從零設計。

應優先：

> 使用母版作為參照 / 編修基礎，只改本次情緒需要變化的部分。

### LOCKED｜不可變
- 角色身份
- 臉部骨架
- 頭身比
- 頭部大小
- 肩寬
- 身體長度
- 髮型大輪廓
- 毛髮配置
- 服裝結構
- 配件位置
- 主要配色
- 畫風
- 像素密度
- 輪廓粗細
- 朝向
- 畫面占比
- 裁切尺度

### CHANGE ONLY｜可改
- 眉眼
- 嘴型
- 情緒
- 手勢
- 頭部傾斜
- 身體重心
- 小幅姿勢
- 情緒所需的肢體語言

---

## 9. 建議生產 SOP

### Step 1
先做「普通」母版。

### Step 2
母版確認後凍結。

### Step 3
先測試兩個差異大的表情，例如：

- 開心
- 受傷

確認跨度大時角色仍不漂。

### Step 4
通過後再補：

- 憤怒
- 難過
- 害怕 / 忌憚
- 驕傲
- 無語
- 其他劇情表情

### Step 5
每張完成後都與母版並排檢查。

---

## 10. 常用情緒表現原則

### 憤怒
- 眉眼收緊
- 身體有張力
- 手勢更有壓迫感
- 不改臉型

### 難過
- 眼神下沉
- 身體略縮
- 力量感下降，但不幼兒化

### 害怕 / 忌憚
- 用眼神、低頭、收縮姿態、護身手勢表現
- 強大角色的害怕可表現為戒備或忌憚，不必崩潰

### 開心
- 放鬆眉眼
- 嘴角上揚
- 姿態開放
- 不自動變成可愛 Q 版

### 受傷
- 痛苦
- 收緊身體
- 可抓傷處
- 除非指定，避免血腥流血

### 驕傲
- 抬頭
- 胸肩打開
- 眼神自信
- 可有輕蔑感

### 無語
- 眼神死
- 側眼
- 肩膀鬆
- 可有疲憊 / 嫌棄 / 無奈感

---

## 11. 風格漂移檢查表

每張新立繪都要與母版核對：

| 項目 | 檢查 |
|---|---|
| 頭身比 | 是否仍約 4～4.5？ |
| 頭部大小 | 是否縮小 / 放大？ |
| 肩寬 | 是否改變？ |
| 軀幹長度 | 是否拉長？ |
| 臉型 | 是否變成另一張臉？ |
| 髮型 | 大輪廓是否一致？ |
| 特殊特徵 | 是否缺漏 / 新增？ |
| 像素密度 | 是否突然變精細或模糊？ |
| 光影 | 是否突然換成另一套 rendering？ |
| 畫面占比 | 是否忽近忽遠？ |

---

## 12. 禁止事項

- 不可同一角色每張像不同人。
- 不可表情一改，頭身也跟著變。
- 不可受傷就自動流血。
- 不可強大角色自動變高挑。
- 不可突然變半寫實。
- 不可突然變成細線動漫插畫。
- 不可裁切尺度漂移。
- 不可擅自增加或刪除角色重要器官、配件、核心特徵。
- 不可只因「更好看」就偏離母版。

---

## 13. 新對話委託時需提供

1. 本準則。
2. 2～5 張《燃燈劫》核准立繪參考。
3. 若為既有角色：**必須提供標準母版圖**。
4. 角色名稱。
5. 目前情緒 / 動作。
6. 朝向。
7. LOCKED 不可變項。
8. CHANGE ONLY 可變項。
9. 是否需要完整全身。
10. 是否有固定裁切與人物占比。

---

## 14. 驗收標準

新圖完成後，先問：

> **「這是不是同一個角色？」**

再問：

> 「這張表情畫得好不好？」

只要第一題不成立，即使單張再漂亮也不通過。

- [ ] 臉是同一人。
- [ ] 頭身一致。
- [ ] 服裝一致。
- [ ] 髮型一致。
- [ ] 主要特徵一致。
- [ ] 朝向一致。
- [ ] 畫面占比一致。
- [ ] 像素密度一致。
- [ ] 情緒清楚。
