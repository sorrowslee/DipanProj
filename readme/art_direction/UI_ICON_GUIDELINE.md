## 0. 一句話定義

**暗石＋暗銅底，細暗古金收邊，一個節制的點綴色；霧面、低雜訊、無光暈；佛教恐怖題材但畫面安靜。**

英文版（放進每一則 prompt）：
`calm dark stone and dark bronze surfaces, thin dull antique-gold trim, one restrained accent color, matte, low texture noise, no glow, Buddhist-horror theme but visually quiet`

## 1. 色彩（必須遵守）

### 1.1 主色票（取自已定稿素材的實際取樣）

| 用途 | 色值 | 說明 |
|---|---|---|
| 最深底（陰影、凹槽） | `#0A0805` ~ `#130F0A` | 面板底色，接近黑但帶暖 |
| 石面／面板主體 | `#16130D` ~ `#251C12` | 大面積用這段 |
| 暗銅（框體、金屬物件） | `#2E211A` ~ `#4E3626` | 框與器物的主體 |
| 銅中間調 | `#513B21` ~ `#90613B` | 框的受光面 |
| 暗古金（細收邊、高光） | `#B08A55` ~ `#D9AD79` | **只用在細線與小高光**，不可大面積 |
| 點綴：深緋紅 | `#3D0908` ~ `#7A1A14` | 按鈕面、寶石、流蘇；漆器感，不是鮮血 |
| 淡骨色（例外面） | `#D9CBB0` ~ `#E8DCC4` | **只有**程式用深色字的牌子才用（見 §4.4） |

### 1.2 禁止

- ❌ **紫色**（舊介面的紫色已全部移除）。例外：道具本身的固有色，例如紫水晶、虛空法術，只限出現在圖示主體內。
- ❌ 鮮紅、螢光色、霓虹色、飽和度高的黃（舊讀取條的亮黃塑膠感就是反例）。
- ❌ 大面積亮金。金色只能是**細線**（框線粗約為物件短邊的 1～3%）與小高光。
- ❌ 純黑 `#000000`、純白 `#FFFFFF`。
- ❌ 同一張圖出現兩個以上的點綴色（圖示的「主體固有色」不算點綴，見 §5）。

## 2. 材質與光（必須遵守）

1. **材質只有四種**：暗石、暗銅／古銅、骨／淡石、漆面（深緋紅漆）。圖示主體可以有自己的材質（皮革、布、水晶、葫蘆），但**框、底座、配件仍用上面四種**。
2. **霧面**：不可有塑膠反光、鏡面反射、油亮高光塊（gloss blob）。
3. **光源固定左上**，柔和；陰影往右下。所有素材一致。
4. **低雜訊**：
   - 不可有：裂紋噪點、灑點、刮痕滿佈、風化斑駁、髒污噴濺、滿版紋理。
   - 可以有：大面積平滑漸層、少量淺浮雕紋樣（低對比）。
   - 判斷法：縮到 64×64 時，面板應看起來像平滑的色塊，不是一片雜訊。
5. **無光暈**：禁止 outer glow、bloom、發光邊、粒子、火星、閃光星芒、魔法光圈。
   - 唯一例外：選取框（SelectFrame）可以有**極淡**的暖色邊光，用來表示「被選中」。
6. **無墨跡、無血漬噴濺、無潑墨筆觸**。帶「血」的意象一律改成**深緋紅漆面或寶石**表現。
   - 原因：ChatGPT 會把潑血筆觸判定為暴力內容而拒畫，而且潑濺本身就是雜訊。
7. **裝飾語彙**：蓮花紋（小）、捲草紋、佛龕屋簷、垂穗、銅釘、菱形寶石。
   - 每張**最多一個**視覺焦點裝飾，例如頂端一朵小蓮花。不可滿版堆疊。

## 3. 輸出格式（違反就無法使用）

1. **背景**：純平灰 `#808080`，整張畫布只有灰與物件。
   - 不可有：地面、陰影投在地上、漸層背景、暗角、邊框、浮水印、文字、標籤、格線。
2. **比例**：只用三種，由使用者指定。
   - `1:1`（1024×1024）
   - `3:2` 橫向（1536×1024）
   - `2:3` 直向（1024×1536）
3. **物件四周留白**：至少佔畫布邊長的 4%，物件不可貼邊或出界。
4. **不可加入任何文字**：中文、英文、數字都不行。
   - 文字一律由程式繪製。
   - 唯一例外：使用者明確要求的單一符號，例如印章上的一個字。
5. **一張圖只回傳一張**，不要附加變體或說明文字。直接出圖，不要反問。

## 4. 面板／框／按鈕（重繪既有 UI 時）

### 4.1 外形鎖死（最重要）

使用者會附上舊圖，新圖必須：

- **外輪廓、位置、大小、比例完全相同**（會用程式比對透明遮罩，重疊率 IoU 要 ≥ 0.85～0.90）。
- **內部空白區（放文字、道具、圖片的窗口）位置與大小完全相同**。程式是用舊圖的像素座標排版的，窗口移動就會疊錯。
- 鏤空的地方維持鏤空，實心的地方維持實心。
- 不可新增或刪除凸出物（尖角、垂穗、把手、端蓋）。可以換材質，不能換形狀。

### 4.2 內容區

- 放文字／圖片的區域一律是**平整、無紋樣的深色**（`#16130D` 一帶）。可以有極淡、低對比的浮雕紋（例如淡曼陀羅），但不能干擾上面的字。
- 不可在內容區畫任何東西：文字、圖、符號都不行。

### 4.3 框

- 結構：暗銅框體 + 一條（最多兩條）細暗古金內線 + 角落小飾。
- 框的粗細照舊圖，不可加粗變成厚重石框，也不可變成一根細線。

### 4.4 文字底色（容易出錯）

畫任何「牌子／按鈕／名牌」前，必須確認上面的**字是什麼顏色**：

| 程式文字色 | 牌面必須是 |
|---|---|
| 亮金／白色字（預設） | 深色面（深石、深緋紅漆） |
| **深色字（例：血統名牌是深血紅字）** | **淺骨色／淺石面**，不可改成深色 |

使用者沒說的話，**先問**，不要猜。（實例：血統名牌第一次被畫成深色，字完全看不見，退回重做。）

### 4.5 按鈕

- 一般按鈕：深石面。
- 主要／確認按鈕：深緋紅漆面 `#3D0908`～`#5A1210`。
- 外加暗銅框與細古金邊，兩端飾物照舊圖形狀。
- 不可有立體塑膠按鈕感、亮面漸層、按下陰影。

### 4.6 進度條、滑桿等「會被程式裁切／拉伸」的素材

- **外形與兩端端蓋的輪廓要逐像素等同舊圖**。程式用固定比例對齊軌道，差幾像素就會凸出框外。
- 填充色只能是霧面暗古金漸層（上緣一條細淡高光、下緣較深琥珀）。不可有亮黃、塑膠高光、紋理。
- 兩端要有淡金亮邊收尾，讓它看起來嵌在框裡，而不是壓在框上。

## 5. 道具／裝備圖示（Inventory Icon）

### 5.1 風格

- **一個物件一張圖**，不帶底框、不帶格子（格子由程式畫）。
- **粗壯、緊湊、好辨認**：縮到 64×64 仍能一眼認出是什麼。
  - 細長物件（杖、刀、旗、槍）一律**斜放 45°**，並加粗。
  - 不可有細如髮絲的部件、長飄帶、大面積透明煙霧。
- 寫實手繪感但乾淨，不是像素風、不是卡通、不是 3D 塑膠渲染。
- 物件**固有色**可以保留（紫水晶、綠毒葫蘆、藍雷光），但：
  - 只佔物件的一部分，金屬部位仍是暗銅／古金。
  - 同一張圖內只有這一個彩色重點。
- 武器圖示的效果（雷光、火焰）只能**小面積、包在物件裡面**，不可往外噴發。

### 5.2 構圖

- 物件置中，佔畫布約 75～85%（程式會再自動正規化大小）。
- **右下角 20% 區域避免放重要細節**：會被等級徽章 Ⅰ/Ⅱ/Ⅲ 蓋住。

### 5.3 批次出圖（強烈建議）

一次畫 6 個，比一張一張畫更一致，也更省額度：

- `3:2` 畫布，**3 欄 × 2 列**。
- 每格一個物件，置中，格與格之間留大空白，**物件不可跨格或碰到格線位置**。
- 不畫格線、不加標籤、不加編號。
- 依使用者指定的順序排（第 1 列左→右，再第 2 列）。

### 5.4 系列一致性

- 同一系列（例如 8 種血統藥瓶）：瓶身外形、大小、角度、光源完全一致，只換主色與圖騰。
- 同一系列要在**同一則對話**、盡量**同一張圖示表**內完成。

## 6. 一律不要做的事（Reject List）

出現任一條，該張圖作廢：

1. 背景不是純平 `#808080`，或有地面陰影、暗角。
2. 出現任何文字、數字、浮水印、簽名。
3. 物件超出畫布或貼邊；圖示表的物件跨格。
4. 重繪 UI 時外形、窗口位置、凸出物和舊圖不同。
5. 有光暈、粒子、火星、星芒、bloom。
6. 有紫色（固有色例外見 §1.2）、鮮紅、螢光色、亮黃塑膠感。
7. 有潑墨、血漬、噴濺、髒污、滿版裂紋。
8. 金色大面積出現（框體整片金、按鈕整顆金）。
9. 一張圖裡出現兩個以上的點綴色。
10. 淺字牌被畫成淺底、深字牌被畫成深底（見 §4.4）。

## 7. Prompt 範本（直接複製）

**單行貼上**：換行會讓訊息提前送出。

### 7.1 重繪既有 UI（附舊圖）

```
Generate an image now, no questions. Same APPROVED UI STYLE as this chat: calm dark stone and dark bronze surfaces, thin dull antique-gold trim, one restrained accent color, matte, low texture noise, no glow, no purple. Restyle the newly attached piece: <一句話描述：這是什麼、有哪些部件、哪裡是放文字的空白區>. <材質指定，例如 face in deep muted dark lacquer red / plain dark stone face>. LOCKED: same shape, position, size, silhouette and same empty content area as the attached image; plain flat grey #808080 background with nothing else; <1:1 square | 3:2 landscape | 2:3 portrait> output.
```

### 7.2 新的道具圖示表（6 個一張）

```
Generate an image now, no questions. Exactly the same inventory icon style as this chat: one object per icon, bold compact readable silhouette, painterly but clean, matte dark bronze / bone / dull antique gold with one restrained accent color, soft top-left light, crisp edges, low texture noise, no glow, no particles, no text. Make ONE sheet: 3 columns x 2 rows, each object centered in its own cell with wide empty margins, nothing crossing cells, no grid lines, no labels, plain flat grey #808080 background, 3:2 landscape. Order row 1: 1,2,3; row 2: 4,5,6. 1 <物件>, 2 <物件>, 3 <物件>, 4 <物件>, 5 <物件>, 6 <物件>.
```

### 7.3 開新對話時

第一則訊息必須**附上風格錨點圖**（已定稿的圖示總表或面板總表），並在 prompt 開頭寫：

`IMAGE 1 is our APPROVED UI STYLE ... IMAGE 2 is the piece to restyle ...`

同一則對話超過約 12～15 張就開新對話，否則風格會漂移。

## 8. 驗收清單（每張出圖後自查）

- [ ] 背景是純平灰，沒有其他東西。
- [ ] 外形／窗口和舊圖重疊（UI 重繪）；物件完整未出界（圖示）。
- [ ] 縮到 64px 還認得出來，看起來不雜。
- [ ] 金色只有細線和小高光。
- [ ] 只有一個點綴色，沒有紫、沒有螢光、沒有光暈。
- [ ] 牌面深淺和程式字色相配。
- [ ] 和同系列已定稿的圖擺在一起，看不出是不同批次。

## 9. 等級系列（LV1～LV3、血統 Ⅰ～Ⅲ 等）

- 核心物件保持不變，一眼看得出是同一個東西的升級版。
- 等級差異只用：外框／金屬配件變豪華、紋樣增加、點綴色寶石變大或變多。
- **不可用光暈、發光、粒子來表現等級**（§2.5）。

## 10. 可拆分性

- 底板、icon、箭頭、裝飾、符號都要能獨立成一張圖；文字一律不畫（由程式或 Texts/ 文字圖負責）。
- 要求拆圖時：重新繪製成完整獨立元件，不可只裁切原圖、不可帶入周圍其他 UI、不切邊、保持原本比例與造型。

## 11. 文字圖（Resources/UI/Texts/）

- ChatGPT 畫中文字形不可靠，**不要委託 ChatGPT 畫文字圖**；文字圖另循在地化流程（見 [../LOCALIZATION.md](../LOCALIZATION.md)）。
- 既有文字圖的系列字體風格維持不變；中英版要看起來是同一套 UI，不可為塞字改壞底板比例。

## 12. 程式端會怎麼用這些圖（出圖前要知道）

- 物品 icon 經 `IconFit` 依**不透明內容**自動正規化大小（[../INVENTORY.md](../INVENTORY.md)〈icon 規格〉），所以圖示的透明留白多寡不影響大小，但**物件本身要完整、置中**。
- 圖示一律放 `Resources/UI/Icons/`，**不可借用** `Resources/Weapon/`（投射物圖）或特效動畫幀當 icon：投射物圖要配合戰鬥畫面、特效幀縮小後糊成一團，兩者都不是圖示。
- 面板／按鈕的排版常數是用**舊圖像素座標**寫死的（各面板文件有座標表），所以重繪時外形與窗口鎖死（§4.1）。

## 13. 新對話委託時需提供

1. 本準則（整份）。
2. 風格錨點圖：已定稿的圖示總表或面板總表（`TempImage/ui_restyle/` 的 overview 圖）。
3. 類型：UI 重繪／新 UI／武器／道具／技能／技能珠。
4. 要重繪的舊圖，或新元件的用途與比例。
5. 上面要放什麼顏色的字（§4.4）。
6. 是否為系列（LV 或同系列多張）。
