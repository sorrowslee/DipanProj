# 武器集氣模式

## 使用方式

在 `DipanProj_Main/Assets/Data/RecipeTable.csv` 的 `集氣模式` 欄填 `1` 或 `true` 即可啟用；留空、`0` 或 `false` 都視為關閉。欄位省略時預設也是 `false`，舊配方不需要補值。

`集氣時間縮減` 是百分比欄位，留空預設 `0%`：

- `30%`：減少 30%，集氣時間為 `3 × (1 - 0.3) = 2.1` 秒。
- `-20%`：延長 20%，集氣時間為 `3 × (1 - -0.2) = 3.6` 秒。
- 也接受不帶 `%` 的數字，例如 `30` 等同 `30%`。

為避免集氣時間成為零或負數，縮減上限為 `99%`；負值最低限制為 `-1000%`。格式無法解析時會警告並退回 `0%`。

啟用後，空白鍵與滑鼠左鍵共用同一套集氣狀態：

1. 按下任一攻擊鍵時開始集氣，不會立刻發射。
2. 集氣期間顯示 `scifi_charge_up_003` 藍色循環版。
3. 達到配方的集氣時間後立即換成紅色循環版，表示集氣完成。
4. 兩個攻擊鍵都放開時施放；只要其中一鍵仍按住，集氣就繼續。
5. 未滿 3 秒放開：使用原始傷害與原始外型。
6. 滿 3 秒後放開：該次施放傷害變為 3 倍，投射物、發射／命中／軌跡特效與地面法陣視覺變為 2 倍。

倍率使用「單次施放快照」，不會修改 `WeaponTable.csv` 或共用的 `WeaponData`，後續普通射擊不會殘留倍率。魔力消耗仍依原武器的 `ManaCost`，冷卻仍依 `FireInterval`；冷卻未結束時不能開始集氣。

## 互斥規則

集氣只適用於放開後產生一次施放的離散武器。以下持續輸入模式不能使用：

- `IsLaser = 1`：雷射以及底層走雷射路徑的火焰噴射器。
- `IsAura = 1`：佛光等按住期間持續存在的光環。

若資料列同時開啟 `集氣模式` 與上述任一欄位，`RecipeManager` 會輸出警告並把該配方的集氣模式停用，持續型武器仍按原方式運作。這項防呆放在資料載入層，因此玩家輸入端不會進入互相搶按鍵的狀態。

目前專案其他模式（一般投射物、分裂／反彈／追蹤、拋物線、環繞、連鎖、落雷、定點法陣、近身扇形、突進與召喚）都是單次觸發，可以選擇啟用集氣。

## 特效資源

原始素材來自：

- `DipanProj_MapEditor/Effects/Sci-fi/scifi_charge_up_003/blue`
- `DipanProj_MapEditor/Effects/Sci-fi/scifi_charge_up_003/red`

兩套都是 16 幀、128×128。遊戲內整理為：

- VFX ID 27：`Resources/VfxEffects/ChargeUpBlue/ChargeUpBlue_01～16`
- VFX ID 28：`Resources/VfxEffects/ChargeUpRed/ChargeUpRed_01～16`

兩者在 `VfxTable.csv` 以 16 FPS、無限循環設定。正常放開、切換武器、死亡或玩家物件銷毀時會清除；換地圖與暫停／阻擋操作的 UI 則保留集氣狀態。

集氣特效不採固定尺寸。每次生成藍光或切換紅光時，會讀取角色當下 `SpriteRenderer.bounds.size.y` 的實際世界高度，將特效最終高度調整為角色的 `1.15` 倍，因此會比角色大一點，並能跟隨不同血統、動畫尺寸與角色縮放。若當下無法取得 Renderer 尺寸，才退回 `CharacterWorldHeight`。

**2026-08-18 兩項調整**（血統體型倍率帶出來的）：

- **位置改對齊 `PlayerController.BodyCenterWorldPos`**（可見身體中心），不再釘 `transform.position`。
  transform 是畫布中心，體型放大後（腳底錨點）身體整個往上長，釘在 transform 的光圈會沉到小腿附近。
- **體型改變時直接砍掉、下一幀重生**：`RefreshBodyScaledVisuals()` 把 `_chargeVfx` 銷毀即可，
  集氣迴圈每幀都會檢查「`_chargeVfx == null` 就補一顆」，重生時自然吃到新體型、也會自己挑對藍光/紅光。

> ⚠ 集氣光圈是**目前唯一還在讀 `SpriteRenderer.bounds` 量高度**的殘留（只量高、不定位，所以還能用）。
> [PROBLEMS.md](PROBLEMS.md) **E14** 的通則是「別拿 bounds 當可見身體」——日後要動這段時，
> 改走 `PlayerController.VisibleBodyHeight`。

## 轉場與暫停

主遊戲的房間／關卡切換由 `MapManager` 在同一個 Unity Scene 內重建地圖，玩家物件本身會保留。換圖清場仍會刪除舊地圖的所有 `VfxInstance`，但不再清除 `PlayerController` 的集氣進度、完成狀態與集氣武器快照。

- 轉場前仍按住攻擊鍵：轉場期間凍結進度；新地圖恢復輸入後繼續集氣。
- 轉場清掉光圈後：新地圖第一幀會依保存狀態重建藍色集氣光圈或紅色完成光圈。
- 暫停或開啟會阻擋遊戲輸入的 UI：保留狀態並凍結進度，不會中斷，也不會利用讀取／暫停時間累積秒數。
- 在暫停或轉場期間放開按鍵：恢復輸入後偵測到按鍵已放開，才依當時保存的進度施放。
- 轉場後換成不同武器：恢復輸入時取消舊武器集氣，避免把倍率套到另一把武器。

集氣進度使用 `_chargeElapsed += Time.deltaTime`，只在未被 UI 阻擋的正常攻擊更新路徑累加；沒有使用絕對 `Time.time`，因此不會把 LoadingPanel 雖未暫停遊戲的載入時間誤算成集氣時間。
